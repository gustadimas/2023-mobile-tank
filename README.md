# Mobile Tank

Feito em set/2023, na faculdade. Está aqui como arquivo: o código ficou do jeito que era na época.

Exercício da aula de programação mobile de 18/09/2023. Uma torre controlada por toque na tela atira nos inimigos que vão sendo gerados. O controle por toque está no `Torre.cs` e o spawn no `CriarInimigos.cs`.

## Como abrir

Na época só exportei a pasta Assets num `.unitypackage`, então não tem ProjectSettings. Crie um projeto 2D vazio no Unity (nessa época eu usava a 2021.3) e importe `pacote-original/Mobile-Tank-PGMR-18SET23.unitypackage` em Assets > Import Package > Custom Package.

Outros projetos da faculdade: [projetos-da-faculdade](https://github.com/gustadimas/projetos-da-faculdade)
